SEA API

Sistema de Evaluación Académica — REST API para gestión de exámenes, usuarios y evaluaciones académicas institucionales.

📖 Documentación Swagger 📄 ReDoc ⬇ OpenAPI Schema

Módulos

🔐
Authentication
/api/auth/
Login JWT, refresh de tokens, cambio de contraseña y health check.
👤
Users
/api/users/
Gestión de cuentas: estudiantes, profesores y administradores.
📚
Academic
/api/academic/
Períodos, grupos, materias y unidades académicas.
❓
Questions
/api/questions/
Banco de preguntas con opciones de respuesta y niveles de dificultad.
📝
Exams
/api/exams/
Creación, asignación y seguimiento de exámenes.
✅
Answers
/api/answers/
Envío y calificación de respuestas de los estudiantes.
🕵️
Audit
/api/audit-logs/
Registro de actividad y trazabilidad de operaciones críticas.
📊
Reports
/api/reports/
Exportación de calificaciones y reportes académicos en Excel.

Endpoints principales

GET /api/auth/health/ Estado del servicio
POST /api/auth/login/ Obtener token JWT
POST /api/auth/token/refresh/ Renovar access token
GET /api/exams/ Listar exámenes
POST /api/exams/ Crear examen
GET /api/users/ Listar usuarios
POST /api/answers/submit/ Enviar respuestas
GET /api/reports/ Exportar calificaciones
